# 🍕 Pizza Order WinForms

A simple Pizza Ordering System built with C# and Windows Forms.

This project allows users to customize their pizza by selecting the size, crust type, toppings, and dining option, while calculating and displaying the total price in real time.

## Features

- Choose pizza size: Small, Medium, or Large
- Select crust type
- Add multiple toppings
- Choose dining option: Eat In or Take Out
- Calculate the total price automatically
- Display the order summary
- Reset the order form

## Technologies

- C#
- .NET
- Windows Forms
- Visual Studio
